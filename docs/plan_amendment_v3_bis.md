## A. 배경

신청자는 같은 학기 박사과정 **IP-R&D 실습** 과목의 기말 발표 과제를 본
프로젝트 데이터셋의 **선행기술조사(SIRP / examiner-grounded prior-art) 트랙**
을 토대로 작성·발표하고, 담당교수·수강생 피드백을 수렴하려 한다. 이를
현업프로젝트1 계획에 어떻게 반영할지를 본 메모로 명료화한다.

## 1. 선결 — 이중 제출(self-plagiarism) 리스크 차단 ⚠️

현업프로젝트1(채점, 지도교수 신준석)과 IP-R&D 실습(별도 채점, 같은 학기·
과정)에서 **동일 데이터셋의 선행기술조사 부분**을 각 과목 산출물로 사용하는
구조다. 동일·실질동일 작업을 두 과목 학점으로 제출하는 것은 **두 담당교수의
명시적 사전 승인이 없으면 학업 무결성(중복 제출) 위반** 소지가 있다.

**선결 조건 (미충족 시 본 메모 미발효):**

- [ ] 신준석 교수(현업프로젝트1) — 동일 데이터셋의 IP-R&D 실습 병행 사용 +
  각 과목 산출물 범위 구분에 대한 **서면(메일) 승인**
- [ ] IP-R&D 실습 담당교수 — 동일 데이터셋·작업을 본 발표 과제에 사용하는
  것에 대한 **서면 승인**
- [ ] 산출물 범위 구분 문서화: 현업프로젝트1 = SDKB 큐레이션·정합·거버넌스
  전체; IP-R&D 실습 발표 = 선행기술조사 트랙(SIRP/examiner-grounded)의
  *적용·발표* 측면 — 중복이 아닌 **상호 보완 관점**임을 각 산출물에 명시

## 2. 분류 — "외부 참여자" 아님, "외부 검증·피드백 채널"

v3 §A-3의 **외부 참여자**(Bespin Global·POSCO DX·KUKKUK)는 *작업에 기여하는
산업 협력자*다. IP-R&D 실습의 담당교수·수강생은 성격이 다르다:

| 대상 | 역할 | 올바른 분류 |
|---|---|---|
| IP-R&D 실습 담당교수 | 발표에 어드바이스 제공 | **자문/감사표기(acknowledgment)** — 외부 참여자 칸 아님 |
| 수강 동료 학생 | 발표 청중·동료 피드백 | **peer-feedback 채널**(익명 집계) |

→ v3 §A-3 외부 참여자 표는 **수정하지 않는다**. 대신 v3 §D-3(외부 검증·
피드백 채널: 김범수 SME 리뷰 → `docs/feedback/2026w22_kim_review.md`)과
**동일 패턴**으로 확장한다.
