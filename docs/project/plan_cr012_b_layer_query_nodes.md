## 1. 목적 (§0 하류 소비자)

**sdkb-prior-art-paper** 가 B층 확증분할을 개봉하려면 질의 200건이 그래프에 **노드로** 서 있어야
한다. 정답 쪽은 CR-008(문헌 503)·CR-011(청구항 분해)로 이미 닫혔고, 남은 것은 질의 쪽 하나다.

**SDKB-Match·공개 데이터셋 이용자는 움직이지 않는다** — 새 파일 하나가 늘 뿐 기존 파일·T-Box·
IRI 가 전부 그대로이기 때문이다.

## 3. 설계

### 3.1 층 구분은 **파일**로 준다 (요구 ⓑ)

새 술어를 쓰지 않으므로 **T-Box 델타 0** 이고 델타 유형은 ②(개념층)에 머문다. 이 저장소가
**공개되는 기반 온톨로지**라는 사정이 같은 결론을 한 번 더 지지한다 — 논문 평가자산을 도메인
지식과 같은 파일에 섞으면 공개본을 정리할 때 다시 갈라내야 한다.

### 3.3 결정성

수집은 이관 파일 순서를 정본으로 삼고(수집 순서 무관), 빌드는 출원번호 정렬로 돈다.
타임스탬프·난수를 넣지 않는다. **2회 빌드 sha256 동일** — `25e7e993…`.

### 3.4 개념 링크는 자유텍스트 통로만 (승인된 선택)

A층은 통로가 둘이다(`process_family` 구조화 브리지 + 자유텍스트). B층 원천에는 ①의 입력이 없고,
추정해서 채우면 **같은 이름의 다른 것**이 된다(§1.3). 그래서 ②만 적용하고 **비대칭을 리포트에
수치로 남긴다** — A층 IPC4 분포를 같은 리포트에 함께 실어 하류가 "온톨로지 결함"과 "질의 화제의
차이"를 가를 수 있게 한다.
