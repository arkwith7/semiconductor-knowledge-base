## 1. 2단계 분석에서 확정된 사실 (설계의 전제)

이관 파일 `upstream/handoff/CR-008-b-cited-ids.txt` · 514행 · 중복 0 ·
sha256 `9d0a7c0f…8c4b2dff` **대조 일치**.

### 1.1 관할 구성 — CR 기재값과 실측이 일치한다

| 관할 | 건수 | 종별 | 라우팅 | 기존 A층 노드에 이미 존재 |
|---|---:|---|---|---:|
| KR | 235 | A 199 · B1 33 · Y1 3 | KIPRIS Plus | 2 |
| JP | 186 | A 179 · B2 3 · Y2 1 · X2 1 · 기타 2 | BigQuery | 1 |
| US | 51 | A1 41 · B1 4 · B2 4 · A 2 | PatentsView | 0 |
| WO | 24 | A1 22 · A2 2 | BigQuery | 0 |

| EP | 1 | A2 1 | BigQuery | 0 |
| **특허 문헌 계** | **503** | | | **3** |
| NPL(별도 행) | 11 | — | 노드 불가 | — |
| 총계 | 514 | | | |

**분모는 503 으로 동결**(2026-08-03 하류 결정). 회신 시점에 다시 고르지 않는다.

### 1.2 새 식별자 형식 계열은 없다 — 형식 변환은 위험이 아니다

B층의 위험해 보이는 형식 셋이 전부 A층에서 이미 해소된 전례를 갖는다.

| 형식 | B층 | A층 전례 |
|---|---:|---:|
| JP 연호형 8자리 (`JP01033055 A` · 平/昭) | 33 | 40 |
| JP 등록번호 7자리 (`JP4680380`) | 5 | 30 |
| KR 등록/실용 9자리 (`KR100222377 B1` · `KR200287084`) | 36 | 261 |

### 1.3 그러나 종별코드 3종은 A층에 전례가 없다 — **설계 결정 D3 의 대상**

| 종별 | 건수 | 해당 식별자 | 뜻 |
|---|---:|---|---|
| `Y1` | 3 | `KR200287084` · `KR200415562` · `KR200440005` | KR 실용신안 등록공보 |
| `Y2` | 1 | `JP2605509` | JP 실용신안 등록공보 |
| `X2` | 1 | `JP60244476` | JP 특허공고(昭60) |

A층 종별코드는 `A·A1·A2·B·B1·B2·U·U9` 뿐이다.

### 1.4 정규 IRI 규칙은 순수 문자열 변환이다 — 조회가 필요 없다

이관 파일의 각 행은 `prior_art_edges.parquet` 의 **`cited_raw` 와 같은 표기**다. 그래서:

```
cited_id     = "patent:" + country.lower() + "_" + re.sub(r"\s+", "", cited_raw)
node IRI     = <https://w3id.org/sdkb/data/patent/{cited_id 의 ':' → '/'}>
cited_doc_id = f"{CC}-{P|G}-{serial}"     # P/G 는 종별코드로 결정
```

**A층 특허 문헌 3,138건 전량에서 이 규칙이 성립함을 실측 확인**(불일치 75건은 전부 NPL
`patent:other_…` 로, 이 CR 의 대상이 아니다).

종별 → `P|G` 매핑도 A층 실측에서 확정: `A·A1·A2` → **P** · `B·B1·B2·U·U9` → **G**.

### 1.5 기존 파이프라인은 그대로 쓸 수 없다 — **이것이 이 설계의 본체다**

`build_abox_prior_art.py` 는 노드 IRI 를 **`prior_art_edges.parquet` 에서 조회**한다
(`cited_map = dict(zip(cited_doc_id, cited_id))`). B층 문헌은 그 표에 **없고**, 넣을 수도 없다 —
질의–인용 대응이 이관되지 않았고 요구해서도 안 되기 때문이다(CR 비목표 ⓒ · 누출 규율).

`collect_cited_biblio_claims.py` 도 같은 문제를 갖는다 — 모집단을 `cited_population()` 으로
그 표에서 읽는다.

**그러므로 두 스크립트에 "식별자 목록 구동" 입력 경로를 하나씩 더한다. 기존 경로는 건드리지
않는다**(A층 재현성 = 성공기준 ③).

### 1.6 본문 확보 기대치 — A층 실측을 **관할별 분모로** 다시 잰 값

CR 성공기준 ② 는 "JP·WO·CN·EP 초록 ≥ 0.57" 을 A층 하한으로 두지만, 그 0.573 은
`g0_cited` 의 **ja 언어 부분집합 117건**의 값이다. CR 이 지정한 분모(관할별 특허 문헌 수)로
A층을 다시 재면 다음과 같다.

| 관할 | A층 n | 초록 | 청구항 | 개념링크 | IPC | CPC |
|---|---:|---:|---:|---:|---:|---:|
| KR | 1,720 | 0.999 | 1.000 | 0.599 | 1.000 | 0.000 |
| JP | 721 | **0.921** | **0.000** | 0.397 | 1.000 | 0.559 |
| US | 471 | 0.998 | 0.996 | 0.473 | 1.000 | 1.000 |
| WO | 81 | 0.975 | 0.000 | 0.481 | 1.000 | 1.000 |
| CN | 20 | 1.000 | 0.000 | 0.550 | 1.000 | 0.750 |
| EP | 12 | 1.000 | 0.000 | 0.417 | 1.000 | 1.000 |

**하류가 동결한 기준이므로 상류가 바꾸지 않는다.** 리포트는 관할별로 내고, 0.57 과 위 표를
**둘 다** 병기해 하류가 판단하게 한다.

JP 청구항 0.000 은 CR 이 미리 적어 둔 상한(D-05)이다. 고치려 하지 않는다.

### 1.7 연식 — 형식이 아니라 여기가 실제 위험이다

추정 공개연도: 1980년대 5 · 1990년대 32 · 2000년대 143 · 2010년대 263
(등록번호 60건은 번호에서 연도 추정 불가). 1980–90년대 37건은 디지털 초록 자체가
없을 수 있다 — **해소 실패 시 사유를 `note` 에 남기고 리포트에 별도 행으로 보고**한다.

## 2. 설계

### 2.1 새 모듈 — `scripts/build_b_layer_cited_ids.py` (신규 · 작다)

이관 파일 → 수집기가 먹는 모집단 표. **순수 함수 · 네트워크 없음 · 멱등.**

```python
def normalize(raw: str) -> Citation | None:
    """'KR1020090041506 A' → Citation(cc='KR', serial='1020090041506', kind='A').
    특허 문헌 형식이 아니면 None (= NPL)."""

def to_cited_id(c: Citation) -> str:      # 'patent:kr_KR1020090041506A'
def to_cited_doc_id(c: Citation) -> str:  # 'KR-P-1020090041506'

def build(ids_file: Path, out: Path) -> pd.DataFrame:
    """→ data/patents/b_layer_cited_population.parquet
    컬럼 = cited_doc_id · cited_id · cited_country · cited_kind · cited_raw · is_npl
    (= prior_art_edges 의 인용 측 컬럼과 **같은 이름·같은 의미**. 수집기가 그대로 먹는다.)"""
```

- **입력 무결성**: 파일 sha256 을 CR 기재값 `9d0a7c0f…8c4b2dff` 와 대조하고 불일치면 **중단**.
  이관 파일이 조용히 바뀌면 분모 503 이 거짓이 된다.
- **NPL 11 건은 `is_npl=True` 로 표에 남긴다**(버리지 않는다). 리포트의 별도 행이 되고,
  총계 514 병기의 근거가 된다.
- 정렬은 `cited_id` 사전순 고정 — 재실행 시 바이트 동일.

### 2.2 수집기 — `paper_data/scripts/collect_cited_biblio_claims.py` 에 인자 하나

```python
# 기존: cited_population()  ← prior_art_edges.parquet
# 추가: --population <parquet>   주면 그 표를 모집단으로 쓴다. 없으면 기존 동작 그대로.
```

라우팅 로직·스키마·캐시 규칙은 **한 줄도 바꾸지 않는다**. 출력은 소스별 캐시에 누적되며
`cited_doc_id` 로 dedup 되므로, **A층에 이미 있는 3건은 자동으로 재수집되지 않는다.**

### 2.3 노드 실체화 — `build_abox_prior_art.py` 에 IRI 결정 경로 하나

```python
# 기존: cited_map = dict(zip(canon.cited_doc_id, canon.cited_id))   # 엣지표 조회
# 추가: --population <parquet> 이 주어지면 그 표의 (cited_doc_id → cited_id) 를
#       기존 맵에 **덮어쓰지 않고 병합**한다. 충돌 시 기존 값 우선(= A층 불변).
```

- 노드 본체(타입·서지·초록·claimText·IPC/CPC·개념링크)는 A층과 **같은 코드 경로**를 탄다.
  스키마 동일성이 코드로 보장된다.
- **간선은 어느 경로에서도 생성하지 않는다** — `build_abox_prior_art.py` 는 원래 간선을
  만들지 않는다(엣지는 `build_abox_patents.py` 소관). 즉 CR 비목표 ⓐ 는 **코드 변경 없이**
  지켜지며, 회귀 테스트로 고정한다(§4).

**합계 행을 만들지 않는다**(CR 성공기준 ② 의 이유 — 얇은 문서가 채운 0.95 를 성공으로 읽게 된다).

### 2.5 결정성

같은 이관 파일 + 같은 캐시 → 같은 TTL. 타임스탬프를 넣지 않는다(CR-007 규율 동일).
수집 캐시가 없는 상태에서의 네트워크 호출은 **결정적이지 않다** — 그래서 캐시를
`data/patents/cited_enriched/` 에 남기고 `PROVENANCE.json` 에 sha256 을 등재한다.

## 3. 승인이 필요한 설계 결정

| | 결정 | 권고 | 이유 |
|---|---|---|---|
| **D1** | 기존 두 스크립트에 `--population` 인자 추가 | **채택** | 새 스크립트로 복제하면 A층·B층 스키마가 갈라진다. 기존 경로는 인자 없을 때 그대로 |
| **D2** | 신규 파일은 `build_b_layer_cited_ids.py` 1개 | **채택** | §1-8(요청 없는 코드 금지) 안에서 최소 |
| **D3** | 전례 없는 종별 `X2·Y1·Y2` (5건) 처리 | **`Y1·Y2·X2` → `G`(등록/공고)로 매핑하고 리포트에 명시** | 실용신안 등록공보·특허공고는 등록계다. 다만 A층 전례가 없으므로 **해소 결과를 5건 개별로 리포트**해 하류가 검증할 수 있게 한다 |
| **D4** | 성공기준 ② 임계값 | **바꾸지 않는다. 0.57 과 관할별 A층 실측을 병기** | 하류 동결 기준을 상류가 고치면 사후 조정이다 |
| **D5** | 1980–90년대 37건 미해소 시 | **분모에서 빼지 않는다. `unresolved` 에 사유와 함께 남긴다** | 분모를 결과 보고 고르는 것이 §1-3 위반 경로 |

## 4. 5단계 검증 계획 (구현 전에 못박는다)

**(a) 단위**
- `normalize()` — 9개 종별코드 × 6개 관할 · 공백 유무 · NPL 문자열 · 빈 줄
- `to_cited_id()` — **A층 3,138건 전량 왕복 일치**(회귀 테스트로 고정)
- sha256 불일치 시 중단하는가

**(b) 통합**
- **A층 자산 불변**(성공기준 ③): 실체화 전후 `sdkb-abox-prior-art.ttl` 을 그래프 동형으로
  비교해 **기존 3,034 노드의 트리플 변경 0** 을 증명(diff 아닌 트리플 집합 차)
- **간선 0**: 산출 TTL 에 `hasPriorArtExaminer`·`hasPriorArt`·`overPriorArt` 가
  **한 트리플도 없음**을 단정(CR 비목표 ⓐ 를 코드가 지킨다)
- ABox 술어가 전부 T-Box 에 있는가(상류 §5 (b) 표)
- 재현성: 같은 캐시로 두 번 빌드 → 동일 그래프

**(c) 릴리스 게이트**
- `make validate` — `shapes_patent.ttl` × 산출 TTL
- `make test`
- 그래프 서명(클래스별 인스턴스 수)을 `CHANGELOG.md` 에 기록. 하류가 이 숫자로 스냅샷 검증

**하류가 되돌려줄 것**(이 CR 의 승인 조건이 아니다): 재 vendor 후 도달성(분모 503) ·
관할별 본문 확보율 · `make leakage` 통과.
