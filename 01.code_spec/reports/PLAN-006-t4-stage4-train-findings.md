## 0. 결론 먼저

**검토량 200 에서 질의별 회수율은 a′ 7.2% · c1 6.2% 다(train).** **이번 train 에서 시험한 설정 범위에서는** 매개변수로 오르지 않았다. 원인은 두 가지 구조 문제다.

1. **정답의 47% 가 한국어가 아니다**(en 610 · ja 51 / 1,418). 한국어 표현으로 만든 검색식은 이 문서들을 거의 찾지 못한다 — 영어 정답의 **87–95% 가 패싯을 하나도 만족하지 않는다.** 현재 표면형 사전에는 영어 표현이 거의 없다.
2. **모든 요소를 AND 로 묶는 단일 검색식은 진보성(§29②) 인용과 구조가 맞지 않는다.** 심사관은 여러 문헌을 결합하므로 문헌 하나는 청구항 요소의 일부만 개시한다. 한국어 정답 757건 중 a′ 패싯을 **전부** 만족하는 문서는 14건, c1 은 64건뿐이다.

## 3. 설계 변경 제안 (§2 3단계로 되돌아감 · 승인 필요)

| # | 변경 | 근거 | 영향 |
|---|---|---|---|
| R1 | **다중 부분 검색식** — 요소 조합(예: 대표 요소 + 다른 요소 1개)별 검색식을 여러 개 실행하고 **중복 제거 합집합**을 예산 안에서 채운다. 조합 순서·개수·예산 배분은 사전 고정 | §2 — 문헌 하나는 요소 일부만 개시 | S5 를 "단일 검색식 조정" 에서 "부분 검색식 집합 구성" 으로 바꾼다. 총 실행 상한은 다시 정한다 |
| R2 | **언어 간 패싯** — 패싯마다 한국어 표현 OR 영어 표현. 영어는 c 계열이 온톨로지 표면형(개념 라벨·별칭)에서 가져온다. a′ 는 번역 수단이 없다(기준선의 한계로 기록) · b·d 는 LLM 이 스스로 번역 | §2 — 정답 47% 비한국어 | 영어 표면형 결손이 **측정 가능한 온톨로지 결손**이 된다 — 개념별 영어 표면형 보강이 T4 의 첫 어휘 작업 후보 |
| R3 | 집합 중앙값 30 문제 — R1 이 해결하지 못하면 패싯 안 표현 단계(복합어 → 핵심 명사)로 한 단계 완화 | §1 | 없음 |

**R2 는 비교의 공정성에 관계된다.** a′ 에 번역을 주지 않으면 c 대 a′ 의 차이에 "온톨로지 효과" 와 "번역 유무" 가 섞인다. 두 가지 중 하나를 사전에 정해야 한다:
(가) a′ 는 한국어만 — 차이를 "온톨로지가 준 언어 간 연결" 로 해석하고 언어별로 나눠 보고 ·
(나) a′ 에도 기계적 번역(사전 없는 방식)을 준다 — 온톨로지 고유 효과만 분리.

## 4. 사용자 결정 (2026-10-09)

- R1·R2 진행. **a′ 에 공통 번역 제공(나)을 주 기준선**으로, 한국어 전용 a′ 도 보존한다.
- 효과 분리: 네 구성 {기존 · R1만 · R2만 · R1+R2} × {a′, c} 를 train 에서 먼저 비교한다. dev 는 검색 정책·어휘·판정 규칙 동결 뒤.
- R1: 전체 요소 AND 검색식을 **유지**하고 부분 검색식을 더한다. 핵심/주변 요소 구분 · 조합 수 제한 · 개별 과대 결과는 사전 조건으로 좁힘 · 누적 합집합이 예산을 넘으면 **검색식 단위** 채택·축소 · **문헌 ID 순 임의 절단 금지** · 200 은 상한이지 목표가 아니다. a′ 와 c 에 같은 구조·예산.
- R2: 검증된 영어 개념명·동의어(개념 IRI 연결) · 자동 번역 후보(보관·동결) · 문맥 의존 표현(무조건 OR 금지)을 구분하고 출처·버전을 기록한다. 영어 부족만으로 원인을 확정하지 않는다 — 영어 정답 표본에서 필드 누락·형태 처리·필드 범위를 먼저 가른다. **일본어 51 은 분모에 남기고 별도 층으로 보고** — R2 가 일본어를 해결한다고 해석하지 않는다.
- 번역에 LLM 을 쓰면 a′ 를 "LLM 을 전혀 쓰지 않는 비교군" 이라 부르지 않는다 — 번역 전처리와 검색식 생성을 구분해 명시한다.
- d 대 b: 온톨로지의 기여를 영어 표면형에만 좁히지 않는다 — 도구 호출 이력에서 실제 기여(핵심 요소 선택·전문용어 확장·부분 검색 조합)를 확인한다.
