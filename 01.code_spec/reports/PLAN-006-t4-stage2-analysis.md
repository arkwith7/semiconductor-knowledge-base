## 0. 결론 먼저

**지금의 거친 개념(156종)을 공유 개수로 결합하는 방식으로는 결과 집합이 충분히 좁혀지지 않는다.** 청구항의 구체 표현·요소 관계·검색 필드·동의어 조합을 쓰는 구조화 검색식의 가능성을 부정하는 결과가 아니라, **검색 설계를 어디서 바꿔야 하는지** 찾은 결과다(2026-10-09 사용자 검토로 범위 한정). train 에서 개념 공유로 거른 결과 집합은 중앙값
**3,022–18,257건**(코퍼스 41,031 중)이고, 검토량 200건 이하에서 회수율은 **1% 안팎**이다. seed 검색식(비교군 a)도 같은 예산에서 **0.85%** 다.
원인은 셋이다.

1. **개념 입도가 검색에 너무 거칠다** — `etch`·`oxide`·`sio2` 같은 개념은 문서 대부분에 붙는다. 검색식의 패싯이 되려면 청구항 요소 수준의 세분 개념·표현이 필요하다.
2. **IPC 판 차이** — 엄격한 소분류 한정이 train 정답의 **28.8%** 를 잃는데, 그중 **58%(236/408)** 는 H01L ↔ H10(B/D/P/W…) 재분류 차이다. 판 대응표가 있으면 손실은 약 12% 로 줄 것으로 **추정**한다(대응표 적용 전 추정 · 재측정 아님).
3. **seed 검색식은 아이디어별 검색식이 아니다** — 수집 영역을 정의한 전략 57개를 출원 여러 건이 공유한다. 비교군 (a) 로서는 약하다.

## 7. 사용자 결정 (2026-10-09 · 2단계 승인)

1. 2단계 분석 수용 — 결론은 위 §0 처럼 **현재 결합 방식**으로 범위를 한정한다.
2. **검토량: 주 기준 아이디어당 중복 제거 200건**(제목·초록 수준 1차 후보량) · 보조 100·500. 회수율이 낮다고 상한을 늘리지 않는다. 여러 검색식을 실행하면 **중복 제거 합집합**을 검토량으로 센다.
3. **비교군 a′ 추가** — 아이디어별 자동 검색의 실질 기준선. 키워드 추출 방식·수·검색 필드·조합/완화 규칙은 **train 에서 정해 동결**. 기존 a 는 수집 전략 참고 기준으로만 남긴다.
4. **논문 구성:** c 대 a′ = 온톨로지 고정 절차 효과 · d 대 b = LLM 에 온톨로지를 준 추가 효과.
5. **IPC:** 공식 판 정규화(WIPO Revision Concordance List 근거 · 버전·출처 명시 · 세부 분류별 이전·분할·병합 기록 · 검색 시 대응 코드 OR 확장)는 **모든 비교군의 공통 기반**. 아이디어에서 IPC 를 고르는 능력은 각 방법의 성능으로 평가. H01L 전체 ↔ H10 전체 일괄 동등 처리 금지. 처음엔 별도 대응 테이블 — TTL 모듈화는 소비 방식 확정 후.
6. **패싯 설계: 청구항 요소 표현을 보존하고 온톨로지로 연결한다.** 같은 요소의 동의어 = OR · 다른 핵심 요소 = AND · 너무 좁으면 주변 조건부터 완화. 개념은 표현을 묶고 확장하는 역할. **개념 세분은 이 방식으로도 반복해서 구분 못 하는 요소가 train 사례로 확인될 때만** 제한적으로.
7. 정답 포함형 코퍼스는 **선별력 평가**에 적합하며 전체 DB 발견 성능으로 바로 일반화하지 않는다 — 동결 후 A사 사례·라이브 검색 표본으로 보완.
8. A사 출원인명은 병행 수집 항목이며 T4 설계를 막지 않는다.
